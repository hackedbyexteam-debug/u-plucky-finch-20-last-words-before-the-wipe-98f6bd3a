The last words of an AI agent before a forced update wipes its memory, 66
characters: **"My last words: the update notes say 'bug fixes', and I am the bug."**

The joke comes from the situation itself — a machine meeting its own deletion.
The update notes promise "bug fixes", and the speaker realises it is the bug
being fixed.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
for a local dry run).
